# 基础通信系统介绍

## 什么是通信系统？

通信系统是用来传输信息的系统。就像我们打电话、发短信一样，需要把信息从一个地方传到另一个地方。

### 基本组成部分

1. **发送端**：
   - 把信息转换成适合传输的形式
   - 就像把我们的声音转换成电信号

2. **信道**：
   - 传输信息的媒介
   - 可以是空气（无线）、电缆（有线）等

3. **接收端**：
   - 把接收到的信号转换回原始信息
   - 就像把电信号转换回声音

### 基本概念

1. **比特流**：
   - 数字信息的基本单位，由0和1组成
   - 例如：10110101

2. **调制**：
   - 把数字信息转换成适合传输的波形
   - 就像把文字转换成摩尔斯电码

3. **解调**：
   - 把接收到的波形转换回数字信息
   - 就像把摩尔斯电码转换回文字

4. **信噪比(SNR)**：
   - 衡量信号质量的指标
   - 越大表示信号质量越好

### 常见问题

1. **噪声干扰**：
   - 就像电话里的杂音
   - 会影响通信质量

2. **信号衰减**：
   - 信号在传输过程中变弱
   - 就像声音传得越远越小

3. **误码**：
   - 接收到的信息出错
   - 就像听错了别人说的话

### 性能指标

1. **误比特率(BER)**：
   - 衡量通信系统准确性的指标
   - 错误的比特数占总比特数的比例

2. **传输速率**：
   - 每秒能传输的信息量
   - 单位通常是比特/秒(bps)

### 应用场景

1. 移动通信（手机）
2. 无线网络（WiFi）
3. 广播电视
4. 卫星通信
5. 光纤通信
